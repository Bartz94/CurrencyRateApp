# Contributing

Thank you for considering contributing to this project.

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Install dependencies

```sh
npm install
```

Start the development server
```bash
npm run dev
```

## Branch Naming

Please use descriptive branch names:

- feature/add-new-component
- fix/api-error
- update/readme

## Commit Messages

Use clear and concise commit messages.

Examples:

- Add currency history component
- Fix API fetching issue
- Update README documentation

## Pull Requests

Before submitting a pull request:

- Make sure the project builds correctly
- Run tests
- Ensure code is formatted properly

Submit pull requests with a clear description of the changes made.

## Code Style

This project uses:

- TypeScript
- React functional components
- Material-UI
- Redux Toolkit Query

Please follow existing project conventions and keep the code clean and readable.

## Reporting Issues

If you find a bug or want to suggest a feature, please open an issue in the repository.
